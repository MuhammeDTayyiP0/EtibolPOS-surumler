# EtibolPOS — sürümler

Restoranlar için yerel ağda çalışan, Windows 7 uyumlu, dokunmatik ekranlara göre tasarlanmış restoran yönetim sistemi.

## Kurulum

1. [Son sürümün sayfasından](https://github.com/MuhammeDTayyiP0/EtibolPOS-surumler/releases/latest) **EtibolPOS-Kurulum-X.Y.Z.exe** dosyasını indirin.
2. Çalıştırın. Kurulum bilgisayarın görevini sorar:
   - **Ana kasa:** siparişler, yazıcılar ve kayıtlar bu bilgisayarda tutulur (restoranda bir tane).
   - **Ekran:** ikinci kasa veya mutfak bilgisayarı; ana bilgisayarı ağda kendisi bulur.
3. Bilgisayarda **Google Chrome** olmalı (Windows 7 için Chrome 109).

Windows "bilgisayarınızı korudu" uyarısı gösterirse **Ek bilgi → Yine de çalıştır** deyin.

## Güncelleme

Program kendini buradan günceller: **Yönetim → Sistem → Güncellemeleri kontrol et** veya saatin yanındaki EtibolPOS simgesi. Paket dijital imzayla doğrulanır, güncellemeden önce yedek alınır; yeni sürüm açılamazsa önceki sürüme kendiliğinden dönülür. İkinci kasa ve mutfak bilgisayarları yeni sürümü ana kasadan alır.

Bu depoda yalnızca kurulum ve güncelleme dosyaları yayınlanır.
